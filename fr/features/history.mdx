L'onglet Historique vous permet de parcourir vos enregistrements de pas quotidiens dans le temps à l'aide d'une vue calendrier ou d'une liste chronologique.

Le calendrier affiche pour chaque jour votre nombre de pas et une couleur selon votre proximité de l'objectif :

- **Objectif atteint** - Mis en évidence dans votre couleur de thème « complété »
- **Progression partielle** - Teinte plus claire selon le pourcentage complété
- **Aucune donnée** - Pas de mise en évidence

Des icônes d'entraînement s'affichent sous le nombre de pas pour les jours où vous vous êtes entraîné. Les jours futurs sont marqués pour qu'ils ne ressemblent pas à un historique vide.

Naviguez entre les mois à l'aide des boutons fléchés en haut du calendrier. Sur un iPhone Duo déplié, la colonne Historique à côté de l'accueil peut afficher une semaine ou un mois.

Passez en vue liste pour voir vos enregistrements quotidiens dans une liste défilante, affichant :

- Date
- Nombre de pas
- Distance
- Si vous avez atteint votre objectif

## Navigation par mois

Utilisez les contrôles de navigation mensuelle pour passer d'un mois à l'autre. Chaque mois affiche un résumé de votre activité pour cette période.

## Limites de l'historique

| Plan | Accès à l'historique |
|------|---------------------|
| **Gratuit** | 3 derniers mois |
| **Pro** | Historique illimité |

<Note>Passez à Steps Pro pour parcourir votre historique de pas complet au-delà des 3 derniers mois.</Note>

## Changer de vue

Sous iOS 26 et versions antérieures, utilisez le bouton de menu dans le coin supérieur droit pour basculer entre les deux dispositions :

- **Calendrier** - Grille mois par mois avec les nombres de pas quotidiens, les couleurs d'objectif et les icônes d'entraînement
- **Liste** - Liste chronologique de vos enregistrements quotidiens

Sous iOS 27, l'Historique est uniquement le calendrier. Une préférence de liste d'une version antérieure est conservée si vous revenez en arrière, mais elle n'est pas affichée.
