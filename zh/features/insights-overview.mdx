洞察为您提供步数和锻炼数据的年度回顾，包含统计数据、记录和有趣的比较。

## 步数分析

{/* TODO: Screenshot of Insights yearly receipt / steps analytics */}
<Frame caption="洞察年度收据，包含总步数、距离和卡路里">
  <img src="/images/screenshots/insights-yearly-receipt.jpg" alt="Insights yearly receipt" />
</Frame>

您的年度步数摘要包括：

- **年度收据** - 全年总步数、距离和卡路里
- **每日平均** - 您每天的平均步数
- **最佳日** - 您单日最高步数及日期
- **最佳月** - 总步数最多的月份
- **高峰时段** - 您最活跃的一天中的时段
- **工作日分析** - 按星期几比较步数的图表，包含工作日与周末平均值
- **达成目标次数** - 您达到步数目标的总天数
- **最佳连续** - 您最长的连续打卡天数

如果您已设置[年度步数目标](/zh/features/yearly-goal)，进度卡片会显示您今年迄今为止的步数、渐变进度条，以及您是否按计划进行。对于当前年份，它还会根据您的进度预测您的年终总量；对于过往年份，它会显示您达到目标的百分比和每日平均值。

## 锻炼分析

如果您记录过锻炼，您还将看到：

- **锻炼航班票** - 总锻炼次数、锻炼时间、距离和卡路里
- **锻炼分析** - 最常见的锻炼类型、户外与室内次数、工作日与周末活动

## 个人记录

{/* TODO: Screenshot of personal records grid */}
<Frame caption="显示所有时间最佳成绩的个人记录网格">
  <img src="/images/screenshots/insights-personal-records.jpg" alt="Personal records" />
</Frame>

可滚动网格显示您的 8 项全时间个人记录：

| 记录 | 追踪内容 |
|--------|----------------|
| **最快** | 最佳配速 |
| **消耗最多** | 单次锻炼消耗最多卡路里 |
| **最早** | 最早锻炼开始时间 |
| **最大爬升** | 最大海拔爬升 |
| **最长** | 最长锻炼时长 |
| **最远** | 最长锻炼距离 |
| **最晚** | 最晚锻炼开始时间 |
| **最高心率** | 记录的最高心率 |

点击任意记录查看完整的锻炼详情。

## 训练时钟

<Frame caption="显示您通常开始锻炼时间的训练时钟">
  <img src="/images/screenshots/insights-training-clock.jpg" alt="Training clock insight" />

训练时钟按星期映射您的锻炼开始时间，每行一个工作日，列为小时。它会根据您实际训练的时段命名模式——早起鸟、晨间行动者、午休运动员、下班后运动员或夜猫子。

## 周期

工具栏中的菜单可在**整年**与该年的任意单月之间切换。当前年份仅提供截至今天的月份。选择某个月时，**最佳月**会替换为**最佳周**。

使用同一菜单在不同年份之间切换，比较您随时间的活动变化。
